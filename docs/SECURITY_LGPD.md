# Segurança e LGPD

## Medidas implementadas
- Hash de senha com bcrypt
- Autenticação e autorização no backend
- Controle de sessão
- Limitação de tentativas de login
- Logs de auditoria
- Validação de entrada (Zod)
- Headers seguros (Helmet)
- CORS restritivo
- Proteção contra atribuição concorrente

## Recomendações LGPD
- Minimização de dados
- Anonimização/exclusão conforme política de retenção
- Registro de consentimento quando aplicável
- Controle de acesso por necessidade
- Backup criptografado
- Logs sem dados sensíveis
- Plano de resposta a incidentes
